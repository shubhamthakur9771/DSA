# Data Structures & Algorithms (DSA)

A collection of C++ programs and practice problems covering fundamental programming concepts, Object-Oriented Programming, Standard Template Library (STL), and Data Structures & Algorithms.

This repository serves as a personal learning resource and reference for strengthening problem-solving skills, understanding core computer science concepts, and practicing their implementation using C++.

## 📚 Topics Covered

### 1. DSA Programs
Programs covering fundamental Data Structures and Algorithms concepts, with a focus on implementing and understanding common programming problems.

### 2. Object-Oriented Programming (OOP)
C++ Object-Oriented Programming concepts, including:
- Classes and Objects
- Constructors and Destructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

### 3. Standard Template Library (STL)
Practice and implementation of commonly used C++ STL components:
- Containers
- Iterators
- Algorithms
- Standard library utilities

### 4. Arrays
Array-based programming problems and operations:
- Array traversal
- Insertion and deletion
- Searching and manipulation
- Array-based problem solving

### 5. Linked Lists
Fundamental linked list implementations and operations:
- Node creation
- Insertion and deletion
- Traversal
- Linked list manipulation

### 6. Practice Codes
Additional C++ programs, coding exercises, and experimental implementations created during the learning process.

## 🚀 Getting Started

### Prerequisites

Install a C++ compiler such as GCC/G++ and ensure it is accessible from your terminal.

### Clone the Repository

```bash
git clone https://github.com/shubhamthakur9771/DSA.git
```

### Navigate to the Repository

```bash
cd DSA
```

### Compile a C++ Program

```bash
g++ filename.cpp -o output
```

### Execute the Program

```bash
./output
```

On Windows, execute:

```bash
output.exe
```
